- 2026-11-14 — Clarifications I–R (spec silent), not a departure. Fixed before any Step 10 M4 forecast exists:
  - **I. Network:** ReLU hidden layers; one linear output; float64; PyTorch default initialization after `torch.manual_seed(seed)`. “Layers {1, 2}” means hidden layers. Weight decay uses `torch.optim.Adam(weight_decay=wd)` (L2 in the gradient, not AdamW). Full-batch MSE training on the log per-session target (`log rv_30d_per_session`); maximum 3,000 epochs; early stopping on stopping-block MSE, patience 20, strictly lower improvement, with best-epoch weights restored. Count and report folds hitting the cap.
  - **J. Rows and scaling:** Usable training rows are `train_idx` rows where all four inputs and the target are finite, dropping 21 HAR warm-up rows; apply `early_stop_split` to those usable rows. Inputs are logs of M2’s four inputs (RV_d, RV_w, RV_m, IV_t/N_t). Fit the scaler (mean, population standard deviation, ddof 0) on the fit block only; apply it unchanged to stopping and forecast rows.
  - **K. Back-transform and averaging:** For each seed, forecast `F = exp(ŷ + s²/2)`, where s² is the mean squared log-scale residual (ddof 0) of the restored model on all usable training rows (fit + stop). Average the three seeds’ back-transformed per-session forecasts, then multiply by N_t and apply the §3.4 floor for QLIKE, as for M0–M3. MSE and MZ use raw totals.
  - **L. Validation and selection:** Annual validation folds cover forecast dates 2016-01-01 → 2019-11-29: the last session whose 30-day target closes by 2019-12-31, so no 2020 realised variance enters selection (4 folds, 985 forecasts). Score each configuration as the mean over seeds of each seed’s mean floored QLIKE over those 985 dates. Ties within 1e-12 go to fewer parameters, then larger weight decay. Write and commit the selection before computing any test-period M4 forecast.
  - **M. Test run:** Retrain the selected configuration once per calendar year, at the first forecast date of 2020–2026: 7 folds, 1,703 forecasts on exactly the M1 dates.
  - **N. Shuffled-target check (§9.4):** Use the same configuration, folds, and seeds; permute training targets within usable training rows using `np.random.default_rng(fold_year)`. Pass only if its seed-averaged mean floored QLIKE over the 1,703 test dates exceeds M0’s. Report no M4 result unless this passes.
  - **O. Determinism:** CPU only; `torch.use_deterministic_algorithms(True)` and `torch.set_num_threads(1)`; set the seed immediately before building each model.
  - **P. Final Holm (§5.5):** Q1c is DM on floored QLIKE, d = QLIKE(M4) − QLIKE(M2), HAC lag 21. Apply Holm across the four §5.5 DM p-values (M2 vs M1, M4 vs M2, M1 vs M3, M1 vs M0), separately in the full sample (1,703) and ex-window sample (1,632, rule A). A Holm-adjusted p < 0.05 plus sign determines the decision. Reapply rule A.4 to the Holm decisions, replacing the three provisional Step 9 classifications. Report M4 Mincer–Zarnowitz outside Holm.
  - **Q. §8 “holds across regimes” (Q1c):** On the headline sample, M4’s mean QLIKE must be below M2’s in each VIX tercile (§3.5 thresholds 14.89 / 18.57); report point estimates without an additional test. If Q1c rejects for M4 but this condition fails, describe it as “better on average, not across regimes”.
  - **R. PyTorch pin:** Pin PyTorch in `requirements.txt` to the installed version when the code is committed, as §4 specifies.
  Cost to the claim: none. These clarifications were written before any M4 forecast exists; Q1/Q1b/Q1d numbers are unchanged.
